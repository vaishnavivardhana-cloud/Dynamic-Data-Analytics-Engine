# 📊 Dynamic Data Analytics Engine

## 🚀 Overview

Dynamic Data Analytics Engine (DDAE) is an end-to-end analytics platform that enables users to upload datasets, automatically clean and profile data, detect business domains, generate insights, and launch industry-specific Power BI dashboards.

The platform integrates **Python**, **Streamlit**, **Pandas**, and **Power BI** to transform raw datasets into actionable business intelligence.

---

## 🎯 Project Objectives

- Automate data cleaning and preprocessing
- Generate quick exploratory insights
- Support multiple business domains
- Provide executive-level Power BI dashboards
- Reduce manual analytics effort
- Improve decision-making through visualization

# ⚙️ Installation

## Clone Repository

```bash
git clone https://github.com/vaishnavivardhana-cloud/Dynamic-Data-Analytics-Engine.git
```

## Navigate to Project

```bash
cd Dynamic-Data-Analytics-Engine
```

## Install Dependencies

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```
